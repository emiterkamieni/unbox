unbox is now available for Windows.

- **Windows**: the same list of folders and files kept offline by Box Drive, in the notification area. Uncheck items and click Apply – unbox frees the space just like *Free up space* in File Explorer. Requires the new Box Drive for Windows (2.47 or later) on Windows 10 22H2 or Windows 11, x64 or Arm.
- Windows installer without administrator rights, light and dark mode, 15 languages and in-app updates with small delta packages.
- **macOS**: no changes besides the version number.

Download `unbox-win-x64-Setup.exe` (most PCs) or `unbox-win-arm64-Setup.exe` (Arm PCs), or `unbox-1.1.0-macos-arm64.zip` for the Mac.
